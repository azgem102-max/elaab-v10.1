## الإصلاحات المطبقة في هذا الفحص

### 1. رقم الإصلاح: P-01، P-09، P-10 — شاشة الملف الشخصي
**الملف:** `artifacts/mobile/app/(tabs)/profile.tsx`

**الخلل كان:** `if (!user) return null` — شاشة فارغة تمامًا بدون أي مؤشر.

**الإصلاح:**
- أُضيفت حالتان: `isLoading` و`loadError`
- Loading state: يعرض `ActivityIndicator` أثناء انتظار البيانات
- Error state: يعرض أيقونة + رسالة + زر "إعادة المحاولة" عند فشل API
- تم تعديل `refreshProfile` في `AppContext` لإعادة رمي الأخطاء (rethrow) بدلًا من ابتلاعها، مما يجعل حالة الخطأ قابلة للوصول فعليًا

**الملف الثاني:** `artifacts/mobile/context/AppContext.tsx`
- أُزيل `catch {}` الصامت من `refreshProfile` — الأخطاء تُرمى الآن للمُستدعي
- جميع المُستدعين الآخرين موجودون مع `.catch(() => {})` مناسب

### 2. رقم الإصلاح: N-02 — شاشة الإشعارات
**الملف:** `artifacts/mobile/app/notifications.tsx`

**الخلل كان:** لا يوجد مؤشر تحميل — empty state تظهر زائفةً قبل اكتمال التحميل.

**الإصلاح:**
- أُضيفت حالة `isLoading` محلية
- `ActivityIndicator` يظهر أثناء `refreshNotifications().finally(() => setIsLoading(false))`
- Empty state تظهر فقط بعد اكتمال التحميل وتأكيد عدم وجود إشعارات
