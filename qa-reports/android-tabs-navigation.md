## 5. شاشة الملف الشخصي — `(tabs)/profile.tsx`

### ❌ الشاشة قد تكون فارغة (خلل حرج)
- **الملف:** `app/(tabs)/profile.tsx` — السطر 152
- **المشكلة:** عند غياب بيانات المستخدم (`!user`), الشاشة تُرجع `null` — أي فراغ تام بدون spinner أو رسالة خطأ.
- **الكود المُسبّب:**
  ```tsx
  if (!user) return null; // السطر 152
  ```
- **السيناريو:** عند انتهاء الجلسة، بطء الشبكة، أو خلل في `AppContext`، الشاشة تبدو بيضاء تماماً.
- **الحل المقترح:** استبدال `return null` بـ:
  ```tsx
  if (!user) return (
    <View style={{ flex: 1, alignItems: 'center', justifyContent: 'center' }}>
      <ActivityIndicator size="large" color={colors.primary} />
    </View>
  );
  ```
- **الأولوية:** حرجة — يُخالف المتطلب: "الشاشة لا تكون فارغة تحت أي ظرف".

### ✅ اسم المستخدم والصورة الرمزية والرياضة
- **الملف:** `app/(tabs)/profile.tsx` — السطور 231–260
- اسم المستخدم: `user.nickname`.
- الصورة: `user.avatarUri` أو حرف أول من الاسم.
- الرياضات: حلقة على `user.sports` مع عرض الاسم والمركز. **✅**

### ✅ مقياس الموثوقية (Reliability Score)
- **الملف:** `app/(tabs)/profile.tsx` — السطور 28–62، 206–228
- `CircularProgress` يعرض نسبة الموثوقية حول الصورة الرمزية.
- Pill بلون ديناميكي يعرض التصنيف (`reliabilityLabel`). **✅**

### ✅ محتوى آخر عند فشل التحميل (جزئياً)
- **الملف:** `app/(tabs)/profile.tsx` — السطور 143–148
- `useFocusEffect` يستدعي `refreshProfile()` + `refreshMatches()` مع `.catch(() => {})`.
- **ملاحظة:** أخطاء التحميل تُمتصّ صامتة ولا تُعرض. إذا نجح التحميل الأولي والمستخدم موجود، تظهر الشاشة. **✅ جزئي**

**`app/(tabs)/profile.tsx` — السطر 152:**
استبدال `return null` بـ spinner أو رسالة خطأ:
```tsx
if (!user) {
  return (
    <View style={{ flex: 1, alignItems: 'center', justifyContent: 'center', backgroundColor: 'transparent' }}>
      <ActivityIndicator size="large" color={colors.primary} />

        جارٍ تحميل الملف الشخصي...
```
