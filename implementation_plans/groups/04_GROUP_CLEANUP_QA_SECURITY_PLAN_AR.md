# خطة 04: التنظيف والاختبارات والأمان

## الهوية

هذه الخطة مسؤولة عن تحويل تحسينات المجموعات من إصلاحات موضعية إلى نظام جاهز للشحن بثقة.

## الهدف

ضبط:

- تنظيف البيانات المرتبطة
- قيود النزاهة
- سلوك الحذف
- سيناريوهات الاختبار
- نقاط الأمان والصلاحيات

## المشاكل الحالية

1. حذف المجموعة لا ينظف كل السجلات التابعة.
2. لا يوجد وضوح كافٍ حول ماذا يحدث للمباريات المرتبطة بالمجموعة عند حذفها.
3. بعض الجداول تحتاج فهارس أو قيودًا أقوى.
4. لا توجد قائمة QA مركزة تغطي كل حالات المجموعة.

## التغييرات المقترحة

### 1. تنظيف الحذف

عند حذف المجموعة يجب معالجة:

- `group_members`
- `group_messages`
- `group_join_requests`
- `group_invites` عند إضافته
- `invite_links` المرتبطة بالمجموعة

### 2. التعامل مع المباريات المرتبطة

المجموعات حاليًا مرتبطة بالمباريات عبر:

- `matches.invitedGroupId`

القرار الموصى به:

- منع حذف المجموعة إذا كانت لديها مباريات قادمة مرتبطة بها

سبب التوصية:

- هذا أكثر أمانًا من حذف أو إلغاء مباريات مستقبلية تلقائيًا بدون قرار صريح

إذا أراد المنتج لاحقًا حذفًا شاملًا بضغطة واحدة، فيجب تصميمه كمسار مستقل ومقصود.

### 3. تحسين قيود قاعدة البيانات

اقتراحات مهمة:

- فهرس على `group_join_requests(group_id, status)`
- فهرس على `group_messages(group_id, created_at)`
- فهرس على `group_invites(invitee_id, status)` بعد إضافته
- قيد يمنع أكثر من دعوة `pending` فعالة لنفس `(groupId, inviteeId)`
- قيد يمنع أكثر من طلب انضمام `pending` فعّال لنفس `(groupId, userId)`

### 4. تحسين الأمان

يجب مراجعة النقاط التالية:

- لا يمكن لغير المشرف دعوة أعضاء
- لا يمكن لغير المشرف إزالة أعضاء
- لا يمكن تعديل دور المالك
- لا يمكن قبول دعوة لا تخص المستخدم الحالي
- لا يمكن استخدام دعوة منتهية أو ملغاة
- لا يمكن قراءة دردشة المجموعة بدون عضوية

## خطة QA المقترحة

### المجموعات العامة

- إنشاء مجموعة عامة
- الانضمام إليها مباشرة
- ظهور العضوية فورًا
- مغادرة المجموعة كعضو عادي

### المجموعات الخاصة

- إنشاء مجموعة خاصة
- إرسال طلب انضمام
- موافقة المشرف
- رفض المشرف
- التحقق من ظهور `pending` بشكل صحيح

### الدعوات

- إرسال دعوة مباشرة
- قبول الدعوة
- رفض الدعوة
- منع التكرار
- انتهاء الصلاحية

### الإدارة

- ترقية عضو إلى مشرف
- تخفيض مشرف إلى عضو
- إزالة عضو
- منع إزالة المالك

### الدردشة

- قراءة الدردشة كعضو
- منع القراءة لغير العضو
- إرسال رسالة
- وصول إشعار للأعضاء الآخرين

### الحذف

- حذف مجموعة بدون توابع
- محاولة حذف مجموعة لديها مباريات قادمة
- التحقق من تنظيف الرسائل والطلبات والدعوات

## تعريف النجاح

تعتبر هذه الخطة ناجحة عندما:

1. لا تترك المجموعات المحذوفة بيانات مرتبطة غير منطقية.
2. كل صلاحية حساسة مغطاة بتحقق واضح في السيرفر.
3. جميع السيناريوهات الأساسية للمجموعات موثقة وقابلة للاختبار.
4. يصبح نظام المجموعات قاعدة مستقرة يمكن البناء فوقها بميزة الأصدقاء.

## التوصية

هذه الخطة يجب تنفيذها مباشرة بعد استقرار:

- العضوية والوصول
- الدعوات
- تزامن الواجهة

لأنها تمثل طبقة الثقة النهائية قبل الشحن أو قبل التوسع.
