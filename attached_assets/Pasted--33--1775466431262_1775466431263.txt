#33 - اختبار: دورة حياة المباراة كاملة
الهدف
اختبار كل ميزة متعلقة بالمباريات: من الشاشة الرئيسية حتى إدارة المباراة وتقييم اللاعبين.

نطاق الاختبار
1. الشاشة الرئيسية (tabs/index.tsx)
 تحميل المباريات القادمة (Skeleton → قائمة)
 حالة "لا توجد مباريات" → EmptyState يظهر
 فلترة بالرياضة (football / padel / tennis)
 بطاقة المباراة: تعرض الرياضة، التاريخ، الملعب، عدد اللاعبين
 الضغط على بطاقة → match-details
 زر FAB "+" لإنشاء مباراة → create-match
 Refresh (سحب للأسفل) → تحديث القائمة
2. شاشة الاستكشاف (tabs/explore.tsx)
 البحث النصي يُصفّي المباريات فوراً
 بحث فارغ → الكل يظهر
 فلتر الرياضة (كرة / بادل / تنس)
 فلتر المستوى (مبتدئ / متوسط / متقدم)
 فلتر التاريخ (اليوم / هذا الأسبوع / الشهر)
 تطبيق فلترين معاً
 مسح الفلاتر → ActiveFilterChips تختفي
 لا نتائج → EmptyState مناسب
 رسالة خطأ API → ErrorBanner يظهر
 الضغط على بطاقة → match-details
3. إنشاء مباراة (create-match.tsx)
 الخطوة 1: اختيار الرياضة (إلزامي)
 الخطوة 2: اختيار التاريخ (لا يُقبل تاريخ ماضٍ)
 الخطوة 3: اختيار الوقت
 الخطوة 4: الملعب (نص حر + اقتراحات)
 الخطوة 5: عدد اللاعبين (slider أو input)
 الخطوة 6: المستوى (مبتدئ / متوسط / متقدم)
 الخطوة 7: رسوم اللعب (اختياري — رقم أو صفر)
 الخطوة 8: وصف (اختياري)
 الخطوة 9: عام / خاص
 زر "رجوع" يعود للخطوة السابقة
 Progress indicator يُحدَّث مع كل خطوة
 إرسال → تُنشأ المباراة + الانتقال لـ match-details
 فشل الإرسال → رسالة خطأ (لا crash)
4. تفاصيل المباراة (match-details.tsx)
قسم الرأس:

 اسم المباراة، الرياضة، التاريخ، الوقت
 شارة الحالة (قادم / اليوم / منتهي)
 زر المشاركة → Native share sheet
 زر الخريطة → يفتح Maps app بالموقع
قسم المنظّم:

 اسم المنظّم + موثوقيته تعرض بشكل صحيح
 زر "التواصل مع المنظّم" → Contact Sheet Modal يظهر
 Contact Sheet: WhatsApp button يعمل (wa.me/...)
 Contact Sheet: زر نسخ الرقم → toast "تم النسخ"
 Contact Sheet: مستخدم لم ينضم → رسالة "الرقم متاح بعد الانضمام"
 Contact Sheet: بدون رقم → رسالة "المنظّم لم يشارك رقمه"
قسم المدفوعات (مراقبة المدفوعات):

 يعرض رسوم اللعب (0 = مجاني)
 قائمة اللاعبين مع حالة الدفع
 اللاعب يمكنه تحديث دفعه الخاص
قسم اللاعبين:

 قائمة اللاعبين مع الصور والمستويات
 عداد "X/Y لاعب"
 مقاعد فارغة تُعرض بشكل مرئي
زر الانضمام:

 "انضم للمباراة" (لاعب جديد) → API call + تحديث القائمة
 "غادر المباراة" (لاعب موجود) → Alert تأكيد → API
 "إدارة المباراة" (المنظّم) → manage-match
 مباراة ممتلئة → زر الانضمام معطّل
حالات الخطأ:

 مباراة غير موجودة → رسالة خطأ واضحة
 خطأ في API → لا crash
5. إدارة المباراة (manage-match.tsx)
تبويب "اللاعبون":

 قائمة اللاعبين مع Swipe actions
 سحب يميناً → "حضر" / "غاب"
 سحب يساراً → "دفع" / "لم يدفع" + "إزالة"
 تغيير الحضور → API call فوري
 تغيير الدفع → API call فوري
 إزالة لاعب → Alert تأكيد → يختفي من القائمة
تبويب "التفاصيل":

 التواريخ والوقت والملعب قابلة للتعديل
 التعديل → PATCH API → تُحفَظ التغييرات
 تاريخ جديد ماضٍ → validation
إغلاق المباراة:

 زر "إغلاق المباراة" → Alert تأكيد
 تأكيد → status يتحول لـ "completed"
 بعد الإغلاق: ينتقل لـ post-match-rating
حذف المباراة:

 زر "حذف" → Alert تأكيد
 تأكيد → DELETE API → الانتقال للخلف
6. تقييم اللاعبين بعد المباراة (post-match-rating.tsx)
 شاشة لكل لاعب بالترتيب (Current/Total)
 أزرار التقييم: ممتاز / جيد / ضعيف
 زر "التالي" → اللاعب التالي (مع animation)
 زر "السابق" (معطّل في اللاعب الأول)
 بعد آخر لاعب: زر "إرسال التقييمات" (معطّل ما لم يُقيَّم أحد)
 إرسال → POST /matches/:id/rate → شاشة نجاح + confetti
 إرسال مسبق (سبق التقييم) → رسالة مناسبة
7. تبويب "مبارياتي" (tabs/my-matches.tsx)
 تبويبان: "قادمة" و"منتهية"
 المباريات القادمة مرتبة تصاعدياً بالتاريخ
 المباريات المنتهية: يظهر زر "قيّم اللاعبين" (إن لم يقيَّم)
 الضغط → match-details أو post-match-rating
 حالة فارغة → EmptyState
8. تعديل المباراة (edit-match.tsx)
 تُحمَّل بيانات المباراة الحالية مسبقاً
 جميع الحقول قابلة للتعديل
 التعديل → PATCH API → تحديث match-details
 مستخدم آخر (ليس المنظّم) → لا يُمكنه الوصول
معالجة الأخطاء المكتشفة
كل bug يُصلَح فوراً في نفس المهمة.
